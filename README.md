# Boost 搜索引擎

## 项目简介

Boost 搜索引擎是一个基于 C++ 和 Boost 库开发的专业搜索引擎，专为搜索 Boost 库文档而设计。该项目实现了完整的搜索功能，包括 HTML 解析、索引构建（正排索引和倒排索引）、分词处理、搜索排序和 HTTP 服务，提供了高效、准确的 Boost 库文档搜索体验。

### 核心索引技术

- **正排索引**：使用向量存储文档信息，通过 doc_id 快速访问完整文档内容，包含标题、正文和 URL 等信息
- **倒排索引**：使用哈希表存储词到文档的映射，支持快速检索包含特定词的所有文档，提高搜索效率

这两种索引结构的结合，使得系统能够在保证搜索速度的同时，提供准确的搜索结果。

## 技术栈

- **编程语言**：C++11
- **核心库**：Boost 库（filesystem、algorithm 等）
- **分词库**：cppjieba
- **HTTP 服务器**：httplib
- **JSON 处理**：jsoncpp
- **构建工具**：Makefile

## 核心功能

### 1. HTML 解析
- 递归遍历目录，收集 HTML 文件
- 提取 HTML 文件中的标题、内容和 URL
- 去除 HTML 标签，提取纯文本内容
- 将解析结果保存为二进制格式，便于后续索引构建

### 2. 索引构建
- **正排索引**：使用向量存储文档信息，通过 doc_id 快速访问
- **倒排索引**：使用哈希表存储词到文档的映射，支持快速检索
- **权重计算**：标题中的词权重高于内容中的词，提高搜索准确性
- **单例模式**：索引模块采用单例模式，确保全局唯一实例

### 3. 搜索功能
- **分词处理**：使用 cppjieba 分词库对查询进行分词
- **停用词过滤**：过滤无意义的停用词，提高搜索效率
- **结果排序**：根据词频和权重对搜索结果进行排序
- **摘要生成**：为每个搜索结果生成包含关键词的摘要
- **JSON 格式**：返回结构化的 JSON 格式搜索结果

### 4. HTTP 服务
- 基于 httplib 实现轻量级 HTTP 服务器
- 提供 RESTful API，支持通过 URL 参数进行搜索
- 静态文件服务，提供搜索页面
- 支持多并发请求处理

## 关键技术

### 1. 倒排索引算法
- 使用 `std::unordered_map` 存储倒排索引，实现 O(1) 时间复杂度的词查找
- 每个词对应一个倒排列表，存储包含该词的文档 ID 和权重
- 索引构建过程中，对标题和内容分别计算词频，赋予不同权重

### 2. 分词技术
- 集成 cppjieba 分词库，支持中文分词
- 实现停用词过滤，提高搜索质量
- 采用单例模式管理分词器，减少资源消耗

### 3. 多线程安全
- 索引模块采用双重检查锁定模式实现线程安全的单例
- 使用 `std::mutex` 确保多线程环境下的安全访问

### 4. 性能优化
- 使用 `std::move` 语义减少内存拷贝
- 采用流式处理，避免一次性加载全部数据到内存
- 搜索结果排序使用高效的 STL 算法

## 快速开始

### 环境要求
- C++11 兼容编译器（如 g++ 4.8+）
- Boost 库（filesystem、algorithm 等）
- jsoncpp 库

### 构建步骤
1. 克隆项目到本地
   ```bash
   git clone https://github.com/ZhuXiaoTianYa/boost-search-engine.git
   cd boost-search-engine
   ```

2. 编译项目
   ```bash
   make
   ```

3. 准备数据
   - 将 Boost 文档 HTML 文件放入 `data/input` 目录
   - 运行解析器生成索引数据
   ```bash
   ./parser
   ```

4. 启动服务器
   ```bash
   ./http_server 8080
   ```

5. 访问搜索页面
   - 打开浏览器，访问 `http://localhost:8080`
   - 在搜索框中输入关键词，点击搜索按钮
